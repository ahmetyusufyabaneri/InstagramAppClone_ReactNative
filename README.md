<h1>Instagram Clone App</h1>

<p>This project is a clone of Instagram, a social media application developed with React Native. Application consists of a home page and a profile page. Users can view posts shared by other users on the home page. At the same time they view their own posts, posts and information on the profile page.</p>

<h2>Used Technologies</h2>

<ul>

<li>react-native</li>
<li>@react-navigation/native</li>
<li>@react-navigation/bottom-tabs</li>
<li>react-native-safe-area-context</li>
<li>react-native-screens</li>
<li>react-native-linear-gradient</li>
<li>dayjs</li>

</ul>
